# Site Controls

**Purpose** — Radian's site popover: connection security, camera, microphone, sound, pop-out view, site data and permissions in one place.

**Commands**
- `site-controls.show` — Site Controls… (cmd+opt+s)

**Settings**
- none

**Tests** — `./forkctl test site-controls`.

**Remove it** — `./forkctl feature disable site-controls`.
