# Downloads

**Purpose** — Downloads fly into the sidebar, show progress, and announce themselves with a toast.

**Commands**
- `downloads.show` — Show Downloads (cmd+shift+j)
- `downloads.open-folder` — Open Downloads Folder
- `downloads.clear` — Clear Downloads List

**Settings**
- `downloads.askWhereToSave` — Ask where to save each file
- `downloads.flyAnimation` — Animate new downloads into the sidebar

**Tests** — `./forkctl test downloads`.

**Remove it** — `./forkctl feature disable downloads`.
