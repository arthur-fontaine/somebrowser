# Tab Switcher

**Purpose** — Arc's Ctrl-Tab: recently used tabs while you hold Control; W closes the highlighted one.

**Commands**
- `tab-switcher.next` — Switch to Recent Tab (ctrl+tab)
- `tab-switcher.previous` — Switch to Recent Tab (Backwards) (ctrl+shift+tab)

**Settings**
- `tab-switcher.allSpaces` — Include tabs from every space

**Tests** — `./forkctl test tab-switcher`.

**Remove it** — `./forkctl feature disable tab-switcher`.
